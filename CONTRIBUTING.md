# Contributing to StudyPlan 🚀

First off, thank you for considering contributing to StudyPlan! It's people like you that make StudyPlan such a great tool.

## 🌈 Code of Conduct

By participating in this project, you agree to abide by our Code of Conduct.

## 🏗️ Getting Started

### Prerequisites

- Node.js (v20.x or higher)
- npm (v10.x or higher)
- A Google Gemini API Key

### Installation

1. Fork the repository.
2. Clone your fork:
   ```bash
   git clone https://github.com/Charushi06/StudyPlan.git
   cd StudyPlan
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Set up environment variables:
   - Copy `.env.example` to `.env`.
   - Add your `GEMINI_API_KEY`.

5. Run the project:
   ```bash
   npm start
   ```

## 🛠️ Development Workflow

1. **Synchronize** your `main` branch with the upstream repository.
2. **Create a new branch** for your contribution:
   ```bash
   git checkout -b feature/your-feature-name
   # or
   git checkout -b fix/your-fix-name
   ```
3. **Implement** your changes following the existing coding style.
4. **Test** your changes locally.
5. **Commit** your changes with descriptive messages:
   ```bash
   git commit -m "feat: add amazing new feature"
   ```
6. **Push** to your fork:
   ```bash
   git push origin feature/your-feature-name
   ```
7. **Open a Pull Request** against the `main` branch.

## 📜 Coding Standards

- Use **Vanilla JS** and **Vanilla CSS** where possible.
- Maintain **Glassmorphism** aesthetics.
- Follow **semantic HTML** practices.
- Use **ARIA labels** for accessibility.
- Keep components modular and reusable.

## 📮 Pull Request Guidelines

- One PR per focused problem/feature.
- Provide a clear title and description.
- Include screenshots for UI changes.
- Ensure all tests pass (if applicable).
- Link the related issue.

## 💡 Reporting Issues

- Use the GitHub Issue tracker.
- Provide a clear title and detailed description.
- Include steps to reproduce for bugs.
- Suggest solutions if you have them!

Thank you for contributing! Happy coding! 🌟
